Monitoreo medioambiental basado en IoT

Propósito: Comprender mediante el uso de sensores y tecnologías de comunicación para monitorear condiciones ambientales en tiempo real.

Tecnologías: [Arduino, Sensor de temperatura, Sensor de humedad]

Características: [Uso activo de sensores para recopilar datos ambientales, transmisión de datos a través de redes inalámbricas, visualización de datos en tiempo real mediante una interfaz web]

Estado: En progreso

IoT in Agriculture 5.0

Propósito: Diseñar e implementar un sistema IoT para la agricultura de precisión, capaz de recopilar datos ambientales en tiempo real y utilizar técnicas de Machine Learning para predecir variables agrícolas y apoyar la toma de decisiones de los agricultores.

Tecnologías:IoT, Arduino UNO, ESP32, sensores ambientales, Cloud Computing, Machine Learning y bases de datos.

Características:Monitoreo de variables como temperatura y humedad mediante sensores, almacenamiento de datos en la nube y utilización de modelos de Machine Learning para realizar predicciones y optimizar recursos agrícolas, la productividad y la calidad de los cultivos.

Estado: Finalizado
