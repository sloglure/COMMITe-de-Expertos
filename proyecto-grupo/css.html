Investigación sobre CSS

Conceptos fundamentales de CSS y su aplicación en nuestro sitio web.

1. ¿Qué es CSS?

CSS significa (Cascading Style Sheets),Es un lenguaje utilizado para definir la apariencia y presentación de los elementos de una página web.

Mientras HTML se encarga de definir la estructura y el contenido de una página, CSS permite controlar aspectos visuales como colores, tamaños, espacios, fuentes, alineación y distribución de los elementos presentes.

HTML:
<h1>Hola</h1>

HTML crea el título dentro de la página.

CSS:
h1 {
    color: blue;
    text-align: center;
}

CSS modifica la apariencia del título, cambiando su color y alineación.

2. Importancia de CSS

CSS es importante, ya que, permite separar la estructura de una página web de su presentación visual. Facilitando así el desarrollo, mantenimiento y modificación del sitio.

HTML → estructura y contenido

CSS → presentación y diseño

Esta separación permite aplicar una apariencia coherente en diferentes páginas del mismo sitio. Por ejemplo, varias páginas pueden utilizar el mismo archivo CSS a fin de mantener los mismos colores, tamaños, márgenes y estilos.

En nuestro proyecto empleamos CSS junto con Bootstrap para mantener una estructura visual uniforme entre las distintas páginas del sitio.

4. Formas de aplicar CSS

CSS en línea

El estilo se coloca directamente dentro del elemento HTML mediante el atributo style.

<p style="color: red;">Hola</p>

CSS interno

Los estilos se colocan dentro de una etiqueta <style> ubicada normalmente en el <head> del documento HTML. 

<style>
    p {
        color: red;
    }
</style>

CSS externo

Los estilos se almacenan en un archivo independiente con extensión .css y posteriormente se enlazan desde el documento HTML.

<link rel="stylesheet" href="../css/style.css">

En nuestro proyecto utilizamos principalmente CSS externo, ya que contamos con diferentes páginas HTML que pueden compartir los mismos estilos. Esto facilita el mantenimiento y permite conservar una apariencia coherente en todo el sitio.

5. Selectores básicos

Los selectores permiten indicar a CSS qué elementos HTML deben recibir determinados estilos.

Selector de elemento

Selecciona directamente un tipo de elemento HTML. 

p {
    color: blue;
}

En este ejemplo, todos los elementos <p> tendrán el texto de color azul.

Selector de clase

Se utiliza mediante un punto (.) seguido del nombre de la clase. 

.card {
    padding: 20px;
}

El estilo se aplicará a los elementos que tengan la clase card.

Selector de ID

Se utiliza mediante el símbolo numeral (#) seguido del identificador. 

#titulo {
    color: red;
}

El estilo se aplicará al elemento que tenga el ID titulo.

6. Clases e identificadores

Las clases y los identificadores permiten aplicar estilos específicos a determinados elementos HTML.

Clase:
<div class="card">

Una clase puede utilizarse en varios elementos diferentes de una misma página. Por ejemplo, varias tarjetas pueden utilizar la clase card para compartir el mismo diseño.

ID:
<div id="principal">

Un ID se utiliza normalmente para identificar un elemento específico dentro de una página. Por esta razón, no debería repetirse para diferentes elementos.

En resumen, una clase es apropiada cuando varios elementos necesitan compartir un estilo, mientras que un ID permite identificar un elemento particular.

7. Modelo de caja

El modelo de caja, o Box Model, describe cómo CSS representa los elementos HTML como cajas. Cada elemento está compuesto por diferentes áreas que determinan su tamaño y separación.

Margin

↓

Border

↓

Padding

↓

Content

Ejemplo:

.card {
    margin: 40px;
    border: 1px solid black;
    padding: 20px;
}

Margin: crea el margen exterior alrededor del elemento.

Border: crea un borde alrededor del elemento.

Padding: crea espacio entre el contenido y el borde.

Content: corresponde al contenido del elemento, como texto, imágenes u otros elementos HTML.

8. Ejemplos de estilos aplicados en nuestro sitio

En nuestro sitio web utilizamos CSS para modificar la apariencia, distribución, tamaño y espaciado de los diferentes elementos de las páginas. A continuación, se presentan algunos ejemplos de estilos utilizados directamente en nuestro proyecto.

Ejemplo 1: Estilo de títulos

Para algunos títulos del sitio utilizamos la clase .H3-Docker, mediante la cual podemos modificar su alineación, tamaño, color y separación respecto a otros elementos. 

.H3-Docker {
    text-align: center;
    font-size: 30px;
    color: #1B5E20;
    margin-top: 50px;
    margin-bottom: 30px;
}
  • text-align: centra el texto del título.
  • font-size: establece el tamaño de la letra en 30 píxeles.
  • color: establece el color del texto.
  • margin-top: genera un espacio superior de 50 píxeles.
  • margin-bottom: genera un espacio inferior de 30 píxeles.

Ejemplo 2: Separación y organización de contenido

La clase .margen-top se utiliza para generar espacio superior y facilitar la organización de los elementos dentro de diferentes secciones del sitio. 

.margen-top {
    margin-top: 80px;
    display: flow-root;
}
  • margin-top: agrega un espacio superior de 80 píxeles.
  • display: flow-root: permite establecer un nuevo contexto de formato para organizar correctamente el contenido del elemento.

Ejemplo 3: Estilo y tamaño de imágenes

Para las imágenes utilizadas en el sitio se utiliza la clase .Imagen1, que permite controlar sus dimensiones, bordes, espaciado y forma en que se adapta la imagen. 

.Imagen1 {
    height: 300px;
    width: 50%;
    border-radius: 20px;
    padding: 10px;
    object-fit: contain;
}
  • height: establece una altura de 300 píxeles.
  • width: establece el ancho en el 50% del elemento contenedor.
  • border-radius: redondea las esquinas de la imagen.
  • padding: genera un espacio interno de 10 píxeles.
  • object-fit: permite que la imagen se ajuste al espacio disponible manteniendo sus proporciones.

Uso de Bootstrap

Además de nuestro CSS personalizado, utilizamos Bootstrap para construir y organizar diferentes elementos de la interfaz. Esto permite utilizar componentes prediseñados y mantener una presentación consistente entre las páginas del sitio.

Ejemplo utilizado en esta misma página:

<div class="panel panel-default">

Las clases panel y panel-default corresponden a componentes de Bootstrap y permiten crear una sección organizada con encabezado y contenido.

Otros componentes de Bootstrap utilizados:
  • panel-heading: define el encabezado del panel.
  • panel-body: contiene el contenido del panel.
  • well well-sm: permite destacar visualmente bloques de contenido.
  • navbar: permite crear la barra de navegación del sitio.

De esta manera, nuestro proyecto combina reglas de CSS propias con componentes de Bootstrap para controlar tanto la apariencia específica de los elementos como la estructura general de las páginas.

Conclusión

CSS es una herramienta fundamental para el desarrollo web, ya que permite controlar la presentación visual de los documentos HTML. Su utilización permite separar la estructura del contenido de su diseño, facilitando el mantenimiento y la reutilización de estilos.

En nuestro proyecto, CSS se utiliza junto a Bootstrap para la creación de páginas organizadas, mantener una apariencia coherente y mejorar la presentación de los contenidos. El uso de hojas de estilo externas permite aplicar reglas comunes a las diferentes páginas del sitio sin tener que repetir el código de estilos.
