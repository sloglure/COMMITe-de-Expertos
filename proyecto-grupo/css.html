Investigación sobre CSS

Conceptos fundamentales de CSS y su aplicación en nuestro sitio web.

1. ¿Qué es CSS?

CSS significa Cascading Style Sheets, que en español se traduce como Hojas de Estilo en Cascada. Es un lenguaje utilizado para definir la apariencia y presentación de los elementos de una página web.

Mientras HTML se encarga de definir la estructura y el contenido de una página, CSS permite controlar aspectos visuales como colores, tamaños, espacios, fuentes, alineación y distribución de los elementos.

HTML:
<h1>Hola</h1>

HTML crea el título dentro de la página.

CSS:
h1 {
    color: blue;
    text-align: center;
}

CSS modifica la apariencia del título, cambiando su color y alineación.

2. Importancia de CSS

CSS es importante porque permite separar la estructura de una página web de su presentación visual. Esto facilita el desarrollo, mantenimiento y modificación del sitio.

HTML → estructura y contenido

CSS → presentación y diseño

Esta separación permite aplicar una apariencia coherente en diferentes páginas del mismo sitio. Por ejemplo, varias páginas pueden utilizar el mismo archivo CSS para mantener los mismos colores, tamaños, márgenes y estilos.

En nuestro proyecto utilizamos CSS junto con Bootstrap para mantener una estructura visual uniforme entre las distintas páginas del sitio.

3. Contenido, estructura y presentación

El desarrollo de una página web puede dividirse en diferentes responsabilidades. HTML define qué elementos existen, mientras CSS determina cómo se muestran visualmente.

Por ejemplo, HTML puede crear un encabezado utilizando <h1>, mientras CSS puede establecer su tamaño, color, fuente y alineación.

4. Formas de aplicar CSS

CSS en línea

El estilo se coloca directamente dentro del elemento HTML mediante el atributo style.

<p style="color: red;">Hola</p>

CSS interno

Los estilos se colocan dentro de una etiqueta <style> ubicada normalmente en el <head> del documento HTML. 

<style>
    p {
        color: red;
    }
</style>

CSS externo

Los estilos se almacenan en un archivo independiente con extensión .css y posteriormente se enlazan desde el documento HTML.

<link rel="stylesheet" href="../css/style.css">

En nuestro proyecto utilizamos principalmente CSS externo, ya que contamos con diferentes páginas HTML que pueden compartir los mismos estilos. Esto facilita el mantenimiento y permite conservar una apariencia coherente en todo el sitio.

5. Selectores básicos

Los selectores permiten indicar a CSS qué elementos HTML deben recibir determinados estilos.

Selector de elemento

Selecciona directamente un tipo de elemento HTML. 

p {
    color: blue;
}

En este ejemplo, todos los elementos <p> tendrán el texto de color azul.

Selector de clase

Se utiliza mediante un punto (.) seguido del nombre de la clase. 

.card {
    padding: 20px;
}

El estilo se aplicará a los elementos que tengan la clase card.

Selector de ID

Se utiliza mediante el símbolo numeral (#) seguido del identificador. 

#titulo {
    color: red;
}

El estilo se aplicará al elemento que tenga el ID titulo.

6. Clases e identificadores

Las clases y los identificadores permiten aplicar estilos específicos a determinados elementos HTML.

Clase:
<div class="card">

Una clase puede utilizarse en varios elementos diferentes de una misma página. Por ejemplo, varias tarjetas pueden utilizar la clase card para compartir el mismo diseño.

ID:
<div id="principal">

Un ID se utiliza normalmente para identificar un elemento específico dentro de una página. Por esta razón, no debería repetirse para diferentes elementos.

En resumen, una clase es apropiada cuando varios elementos necesitan compartir un estilo, mientras que un ID permite identificar un elemento particular.

7. Modelo de caja

El modelo de caja, o Box Model, describe cómo CSS representa los elementos HTML como cajas. Cada elemento está compuesto por diferentes áreas que determinan su tamaño y separación.

Margin

↓

Border

↓

Padding

↓

Content

Ejemplo:

.card {
    margin: 40px;
    border: 1px solid black;
    padding: 20px;
}

Margin: crea espacio exterior alrededor del elemento.

Border: crea un borde alrededor del elemento.

Padding: crea espacio entre el contenido y el borde.

Content: corresponde al contenido del elemento, como texto, imágenes u otros elementos HTML.

8. Ejemplos de estilos aplicados en nuestro sitio

En nuestro sitio web utilizamos CSS para modificar la distribución, los espacios y la apariencia de diferentes elementos de las páginas.

Un ejemplo de estilo aplicado a una tarjeta o sección del sitio es: 

.card {
    max-width: 600px;
    margin: 40px auto;
    padding: 20px;
    text-align: center;
}

En este ejemplo, cada propiedad cumple una función específica:

  • max-width: limita el ancho máximo de la tarjeta a 600 píxeles.
  • margin: genera espacio alrededor de la tarjeta. El valor auto permite centrarla horizontalmente.
  • padding: genera espacio interno entre el contenido y los límites de la tarjeta.
  • text-align: centra horizontalmente el texto contenido dentro del elemento.

Además, en las diferentes páginas del proyecto utilizamos clases proporcionadas por Bootstrap, como container, panel, panel-heading, panel-body, text-center y navbar. Estas clases permiten construir una interfaz organizada y mantener una presentación consistente.

Ejemplo utilizado en esta misma página:

<div class="panel panel-default">

Las clases panel y panel-default proporcionan el diseño visual del panel mediante Bootstrap.

Conclusión

CSS es una herramienta fundamental para el desarrollo web, ya que permite controlar la presentación visual de los documentos HTML. Su utilización permite separar la estructura del contenido de su diseño, facilitando el mantenimiento y la reutilización de estilos.

En nuestro proyecto, CSS se utiliza junto con Bootstrap para crear páginas organizadas, mantener una apariencia coherente y mejorar la presentación de los contenidos. El uso de hojas de estilo externas permite aplicar reglas comunes a las diferentes páginas del sitio sin tener que repetir el código de estilos.
