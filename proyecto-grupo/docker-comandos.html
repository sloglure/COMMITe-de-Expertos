Principales comandos Docker

Explicación y ejemplos de los principales comandos usados en Docker.

1. Consultar la versión de Docker

docker --version

Muestra la versión de Docker instalada actualmente en el equipo. Es útil para comprobar que Docker está instalado correctamente y conocer qué versión se está utilizando.

Ejemplo: docker --version Docker version 28.3.3.

2. Ejecutar un contenedor de prueba

docker run hello-world;

Ejemplo: docker run hello-world;

Docker descargará la imagen si no está disponible localmente y ejecutará un contenedor que mostrará un mensaje indicando que la instalación funciona correctamente.

3. Listar imágenes

docker images

Muestra las imágenes de Docker almacenadas localmente en el equipo.

Ejemplo: docker images

El comando mostrará información como el nombre de la imagen, su etiqueta, ID, fecha de creación y tamaño.

4. Mostrar contenedores en ejecución

docker ps;

Muestra los contenedores que se encuentran actualmente en ejecución.

Ejemplo: docker ps

La terminal mostrará los contenedores activos junto con información como su ID, imagen utilizada, puertos y nombre.

5. Mostrar todos los contenedores

docker ps -a

Muestra todos los contenedores existentes, incluyendo los que están detenidos.

Ejemplo: docker ps -a

Permite revisar contenedores que fueron ejecutados anteriormente pero que actualmente no están funcionando.

6. Construir una imagen

docker build

Construye una imagen a partir de las instrucciones definidas en un archivo Dockerfile.

Ejemplo:
docker build -t mi-web-html .

Docker leerá el Dockerfile de la carpeta actual y creará una imagen llamada mi-web-html, que posteriormente podrá utilizarse para crear un contenedor.

7. Crear y ejecutar un contenedor

docker run

Crea y ejecuta un contenedor utilizando una imagen existente.

Ejemplo:
docker run -d -p 8080:80 --name mi-web-container mi-web-html

En nuestro proyecto, este comando ejecuta el sitio web dentro de un contenedor y permite acceder a él desde el navegador mediante http://localhost:8080.

8. Detener un contenedor

docker stop

Detiene un contenedor que se encuentra actualmente en ejecución.

Ejemplo:
docker stop mi-web-container

El contenedor dejará de ejecutarse, pero seguirá existiendo y podrá iniciarse nuevamente posteriormente.

9. Iniciar un contenedor

docker start

Inicia nuevamente un contenedor que se encontraba detenido.

Ejemplo:
docker start mi-web-container

El contenedor volverá a ejecutarse sin necesidad de crearlo nuevamente.

10. Eliminar un contenedor

docker rm

Elimina un contenedor de Docker.

Ejemplo:
docker rm mi-web-container

El contenedor será eliminado y dejará de aparecer en la lista de contenedores existentes.

11. Eliminar una imagen

docker rmi

Elimina una imagen almacenada localmente.

Ejemplo:
docker rmi mi-web-html

La imagen mi-web-html será eliminada del equipo, siempre que no existan contenedores que dependan de ella.

12. Consultar los registros

docker logs

Permite consultar los mensajes y registros generados por un contenedor.

Ejemplo:
docker logs mi-web-container

La terminal mostrará información registrada por el contenedor, lo que resulta útil para detectar errores o revisar su funcionamiento.

13. Ejecutar comandos dentro de un contenedor

docker exec

Permite ejecutar comandos dentro de un contenedor que se encuentra actualmente en ejecución.

Ejemplo:
docker exec -it mi-web-container sh

Este comando abre una consola dentro del contenedor, permitiendo revisar o manipular elementos de su entorno.
