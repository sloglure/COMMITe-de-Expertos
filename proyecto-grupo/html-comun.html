Etiquetas HTML de uso común

Explicación y ejemplos de las etiquetas fundamentales para la estructura web.

1. Textos y Encabezados

<h1> a <h6>

Definen los títulos y subtítulos. <h1> es el más importante (título de la página) y <h6> el de menor relevancia.

Ejemplo: <h1>Bienvenido a nuestro proyecto</h1>

<p>

Define un párrafo. Se utiliza para bloques de texto normal.

Ejemplo: <p>Este es un párrafo de prueba.</p>

2. Enlaces e Imágenes

<a>

Crea hipervínculos hacia otras páginas. Usa el atributo href para la dirección.

Ejemplo: <a href="index.html">Volver al inicio</a>

<img>

Inserta imágenes en la página. Usa src para la ruta de la imagen y alt para un texto alternativo si no carga.

Ejemplo: <img src="foto.jpg" alt="Foto descriptiva">

3. Listas

<ul>, <ol> y <li>

<ul> crea una lista desordenada (puntos), <ol> una lista ordenada (números). <li> define cada elemento dentro de esas listas.

Ejemplo:
<ul>
  <li>Primer elemento</li>
  <li>Segundo elemento</li>
</ul>

4. Contenedores (Agrupación)

<div>

Es un contenedor de bloque. No tiene diseño propio, sirve para agrupar otros elementos y aplicarles estilos CSS (como los <div class="container"> de Bootstrap).

<span>

Es un contenedor en línea. Permite aplicar estilos a una parte pequeña de un texto sin romper el párrafo.

Ejemplo: <p>Texto normal y <span style="color: red;">texto rojo</span>.</p>

5. Tablas

<table>

Define una tabla para mostrar datos estructurados en filas y columnas.

Ejemplo básico:
<table>
  <tr> <td>Celda 1</td> <td>Celda 2</td> </tr>
</table>

6. Formularios y Captura de Datos

<form>, <label>, <input> y <button>

<form> envuelve todo el formulario. <label> es el texto descriptivo del campo. <input> es la caja de texto donde el usuario escribe y <button> es el botón para enviarlo.

Ejemplo:
<form>
  <label>Nombre:</label>
  <input type="text" placeholder="Ingresa tu nombre">
  <button type="submit">Enviar</button>
</form>
