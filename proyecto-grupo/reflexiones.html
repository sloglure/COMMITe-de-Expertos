Dificultades y Soluciones Aplicadas

Dificultades

La mayor barrera fue la gestión del tiempo. Coordinar el desarrollo con la carga académica de un semestre exigente (balanceando proyectos complejos como Big Data y Ecuaciones Diferenciales), sumado a los turnos laborales de los domingos de algunos integrantes, dejó poco margen de maniobra. Técnicamente, lidiar con errores de rutas locales y entender cómo estructurar correctamente las clases de Bootstrap 3 sin que los elementos se desalinearan fue un desafío importante.

Soluciones

A nivel de equipo, implementamos sesiones de deep work (trabajo profundo) en los tiempos libres dentro de la universidad para avanzar sin distracciones. Para los problemas técnicos, adoptamos la práctica de revisar meticulosamente las rutas en el navegador y utilizar utilidades CSS para forzar la alineación perfecta de las filas, logrando un diseño mucho más profesional.

Aprendizajes Técnicos

HTML & CSS
Comprendimos la importancia de escribir código semántico y modular, separando la estructura (HTML) del diseño (CSS).
Bootstrap 3
Aprendimos a usar el sistema de grillas (Grid) para crear sitios responsivos que se adaptan a cualquier pantalla de forma rápida.
Docker & Nginx
Entendimos cómo contenerizar una aplicación web creando un Dockerfile, lo que nos permite desplegar un servidor Nginx ligero y ejecutar el proyecto en cualquier máquina.

La importancia de la organización del equipo

Este proyecto nos demostró que el desarrollo web va mucho más allá de escribir etiquetas; es un ejercicio de comunicación y arquitectura. Sin una distribución clara de roles, es muy fácil sobreescribir el código del otro o generar interfaces confusas. La colaboración estructurada fue la clave para llegar a un resultado funcional.
