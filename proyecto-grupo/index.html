Nuestro Equipo

¿Quiénes somos?

Somos un equipo de desarrollo web formado por estudiantes de la Universidad Autónoma de Chile, apasionados por el desarrollo de software y superarnos cada día.

Nuestra misión

Nuestra misión es aprobar de manera satisfactoria el ramo de desarrollo web y obtener una buena nota en el proyecto final, además de aprender a trabajar en equipo y mejorar nuestras habilidades de desarrollo web.

Fortalezas

Trabajo en equipo

Combinamos nuestras habilidades individuales para potenciar el resultado final, creando un flujo de trabajo eficiente

Habilidades técnicas

Contamos con algo de experiencia en desarrollo con python , java , c++, complementada con diseño web html

Compromiso

Responsabilidad y organización para cumplir plazos y objetivos.
